# UC‑1: Room Inventory Setup & Management
## Overview
Manages hotel room types, availability counts, and pricing using simple HashMaps.
## Data Structures

HashMap<String, Integer> → room type → available count
HashMap<String, Double> → room type → price per night

## Features
- Add and store room types
- Update room counts and prices
- Reserve and release rooms
- Show real‑time availability

## Flow

- Add room type
- Store in HashMaps
- Update count / price
- Reserve or release
- Display updated inventory
